飞机大战 - 完整射击游戏

🎯 学习目标：综合运用克隆、变量、广播等技术，制作一款完整的射击游戏。

📖 故事背景：驾驶战斗机，消灭从上方飞来的敌机，看看你能坚持多久！

⏱️ 预计时间：60-80分钟

📝 详细操作步骤

第1步：准备角色

  1. 打开Scratch软件
  2. 删除小猫角色
  3. 点击右下角"选择一个背景"，搜索 space，添加太空背景
  4. 点击"选择一个角色"，搜索 rocket，添加我方飞机，改名为"我方飞机"
  5. 搜索 plane，添加敌机角色，改名为"敌机"
  6. 绘制"子弹角色"：用矩形工具画一个黄色小长方形（约10x20像素），改名为"子弹"

第2步：创建变量

  1. 点击左边"变量"分类
  2. 点击"建立一个变量"，创建变量：分数
  3. 再创建变量：生命（初始值3）

第3步：编写我方飞机代码

  1. 点击"我方飞机角色"
  2. 拖出"当绿旗被点击"积木
  3. 添加"将旋转方式设为 [不可旋转]"
  4. 添加"将大小设为 (50)"
  5. 添加"将 [分数] 设为 (0)"
  6. 添加"将 [生命] 设为 (3)"
  7. 添加"重复执行"
  8. 在里面添加"移到 x: (鼠标的 x 坐标) y: (-100)"

  3. 添加"将大小设为 (40)"

  7. 添加"创建 [自己] 的克隆体"

  3. 如何添加道具，吃到后可以增加生命？

坦克大战 - 旋转射击

🎯 学习目标：学会控制角色旋转和方向性射击。

⏱️ 预计时间：70-90分钟

📝 详细操作步骤

第1步：绘制坦克角色

  1. 打开Scratch，删除小猫
  2. 点击"绘制"创建坦克角色
  3. 用矩形工具画绿色长方形作为坦克主体（约40x30像素）
  4. 画深绿色细长方形作为炮管（约30x8像素），指向右边
  5. 在两侧画棕色长条作为履带
  6. 改名为"坦克"

第2步：绘制炮弹角色

  1. 绘制小圆形作为炮弹（直径10像素），用黄色填充
  2. 改名为"炮弹"

第3步：控制坦克旋转

  1. 点击坦克角色
  2. 拖出"当按下 [左移键] 键"，添加"左转 (15) 度"
  3. 拖出"当按下 [右移键] 键"，添加"右转 (15) 度"
  4. 拖出"当按下 [上移键] 键"，添加"移动 (10) 步"
  5. 拖出"当按下 [下移键] 键"，添加"移动 (-10) 步"

当按下 [下移键] 键
移动 (-10) 步

第4步：发射炮弹

  1. 点击炮弹角色
  2. 添加"当绿旗被点击"，添加"隐藏"
  3. 添加"重复执行"
  4. 添加"等待直到 <按下 [空格] 键?> "
  5. 添加"创建 [自己] 的克隆体"
  6. 添加"等待 (0.5) 秒"

第5步：炮弹沿坦克方向飞行

  1. 拖出"当作为克隆体启动时"
  2. 添加"移到 [坦克]"
  3. 添加"面向 [坦克] 的方向"（关键！）
  4. 添加"显示"
  5. 添加"重复执行直到 <碰到边缘?>"
  6. 在里面添加"移动 (15) 步"
  7. 添加"删除此克隆体"

面向 [坦克] 的方向

太空射击 - 多种敌人

🎯 学习目标：学会设计多种敌人类型和Boss。

📝 详细操作步骤

核心思路

  1. 创建变量"敌人类型"，用随机数选择敌人（1=小行星，2=外星人，3=Boss）
  2. 不同敌人有不同的移动速度和血量
  3. 小行星：移动慢，血量1，得分10
  4. 外星人：移动中，血量2，得分20
  5. Boss：移动慢，血量10，得分100

水果忍者 - 滑动切割

🎯 学习目标：学会检测鼠标划过轨迹。

📝 详细操作步骤

核心思路

  1. 水果从底部向上抛物线运动
  2. 检测"碰到鼠标指针"，如果碰到就得分
  3. 炸弹角色：碰到炸弹游戏结束

植物大战僵尸 - 塔防游戏

🎯 学习目标：学会设计塔防类游戏。

📝 详细操作步骤

核心思路

  1. 点击舞台种植植物（消耗阳光）
  2. 植物每2秒发射一颗豌豆
  3. 僵尸从右边出现，向左移动
  4. 阳光随机掉落，点击收集

愤怒的小鸟 - 物理抛射

🎯 学习目标：学会模拟抛物线运动。

📝 详细操作步骤

核心思路

  1. 创建变量"速度x"和"速度y"
  2. 拖动小鸟计算初始速度
  3. 飞行时：x增加速度x，y增加速度y，速度y减少（模拟重力）
重复执行
将 x 坐标增加 (速度x)
将 y 坐标增加 (速度y)
将 [速度y] 增加 (-1)

音乐节奏 - 音游基础

🎯 学习目标：学会设计音乐节奏游戏。

📝 详细操作步骤

核心思路

  1. 音符从上方下落
  2. 到达判定线时按对应键
  3. 判断按键时音符位置是否接近判定线
  4. 接近则得分，否则扣分

关卡编辑器 - 自定义关卡

🎯 学习目标：学会设计关卡编辑功能。

📝 详细操作步骤

核心思路

  1. 创建列表"障碍物X"和"障碍物Y"
  2. 点击舞台时记录鼠标位置，添加到列表
  3. 创建障碍物克隆体
  4. 加载关卡时读取列表数据创建障碍物
