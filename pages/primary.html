🌱 初级篇

适合零基础学习者，从认识Scratch开始，掌握基础运动和控制

1

你说我画 - 认识坐标系

🎯 学习目标：理解什么是坐标，学会用两个数字描述位置。

📖 故事背景：小明想告诉小红在纸上画一个圆点，但是怎么才能让小红画在正确的位置呢？让我们一起来玩"你说我画"的游戏吧！

📝 详细操作步骤

第1步：准备材料

📌 你需要准备：

  • 一张白纸
  • 一把尺子
  • 一支铅笔
  • 一个橡皮
  • 找一个小伙伴一起玩

💡 小贴士：两个人面对面坐好，每个人面前都放一张白纸。

第2步：画一条横线

📌 操作方法：

  1. 用尺子在白纸中间画一条横着的直线
  2. 在线的最左边写上数字 0
  3. 从0开始，每隔1厘米画一个竖线，写上数字 1、2、3、4、5...

🔍 观察一下：现在你可以说"在第3条竖线旁边画一个圆"，小伙伴就能画对啦！

第3步：添加竖线（重要！）

📌 操作方法：

  1. 在刚才画的横线上方，每隔1厘米画一条竖着的虚线
  2. 在下方也画同样的竖线
  3. 现在纸上出现了一个个小格子

❓ 想一想：如果只说"在第3格画圆"，小伙伴能画对吗？为什么不对呢？

💡 答案：不对！因为第3格有很多个，不知道是上面还是下面！

第4步：给竖线也加数字

📌 操作方法：

  1. 在纸的最左边，从中间开始写 0
  2. 向上每隔1厘米写 1、2、3...
  3. 向下每隔1厘米写 -1、-2、-3...（注意是负数！）

✅ 成功啦！现在你可以说"横3，竖2"或者用数学写法"(3, 2)"来告诉小伙伴位置了！

第5步：认识Scratch中的坐标

📌 Scratch中的坐标：

  • 横线叫做 X轴（左右方向）
  • 竖线叫做 Y轴（上下方向）
  • 舞台的最左边 X = -240
  • 舞台的最右边 X = 240
  • 舞台的最下边 Y = -180
  • 舞台的最上边 Y = 180
  • 舞台正中间是 (0, 0)
📝 记住公式：
X坐标决定左右位置（负数在左，正数在右）
Y坐标决定上下位置（负数在下，正数在上）

🤔 课后思考题

  1. 如果小猫在坐标 (100, 50)，它是在舞台的左上角还是右上角？
  2. 坐标 (-100, -50) 在舞台的哪个位置？
  3. 舞台中心点的坐标是多少？
点击查看答案
  1. 右上角（X是正数在右边，Y是正数在上边）
  2. 左下角（X是负数在左边，Y是负数在下边）
  3. (0, 0)

💡 重点知识总结

✨ 坐标就是用两个数字来确定一个位置

✨ 第一个数字叫 X坐标（决定左右）

✨ 第二个数字叫 Y坐标（决定上下）

✨ 写法：(X, Y) 例如：(100, 50)

2

认识角色的坐标值

🎯 学习目标：学会在Scratch中查看角色的坐标，理解坐标变化规律。

📖 故事背景：小猫要去棒球场跑步，让我们看看它跑到每个垒包时的坐标是多少！

📝 详细操作步骤

第1步：打开Scratch编辑器

📌 操作方法：

  1. 打开浏览器（比如Chrome或Edge）
  2. 在地址栏输入：scratch.mit.edu
  3. 点击页面左上角的"创建"按钮（橙色按钮）
  4. 等待编辑器加载完成，你会看到一只橙色的小猫

💡 小贴士：如果网页打开很慢，可以多等一会儿，或者换一个浏览器试试。

第2步：添加棒球场背景

📌 操作方法：

  1. 看屏幕右下角，找到"选择一个背景"按钮（图标是一张图片）
  2. 点击后会弹出一个窗口
  3. 在搜索框中输入：baseball（棒球场的英文名）
  4. 找到"Baseball"图片，点击它
  5. 现在舞台背景变成了棒球场！

🔍 观察一下：你能看到本垒（最下面的那个垒包）在哪里吗？

第3步：拖动小猫到本垒

📌 操作方法：

  1. 用鼠标点击舞台上的小猫角色
  2. 按住鼠标不放，把小猫拖动到本垒（最下面的垒包）
  3. 松开鼠标
  4. 看屏幕右上方，找到角色信息区域
  5. 你会看到 x: 和 y: 后面有数字
  6. 把这两个数字记下来！
📝 记录本垒坐标：x = _____，y = _____

第4步：记录四个垒包的坐标

📌 操作方法：

  1. 把小猫拖到一垒（本垒右边的垒包），记录坐标
  2. 把小猫拖到二垒（最上面的垒包），记录坐标
  3. 把小猫拖到三垒（本垒左边的垒包），记录坐标
  4. 把小猫拖回本垒，记录坐标
位置 X坐标 Y坐标

一垒 约 100 约 -80
二垒 约 100 约 80
三垒 约 -120 约 80

第5步：用积木验证坐标

📌 操作方法：

  1. 看屏幕左边，找到"运动"分类（蓝色积木）
  2. 点击"运动"，你会看到很多蓝色的积木
  3. 找到"移到 x: ( ) y: ( )"这个积木
  4. 用鼠标拖动这个积木到中间的脚本区（灰色的区域）
  5. 在 x: 后面的白框里输入：-120
  6. 在 y: 后面的白框里输入：-80
  7. 点击这个积木一次（点击积木本身）
  8. 观察小猫是否移动到了本垒！
移到 x: (-120) y: (-80)

💡 小贴士：点击积木后，小猫会"嗖"的一下移动到你设置的坐标位置！

🤔 课后思考题

  1. 本垒和一垒的Y坐标为什么差不多？（提示：想想它们的位置关系）
  2. 如果要让小猫从一垒移动到二垒，X坐标要怎么变？Y坐标呢？
  3. 你能用"移到"积木让小猫跑到二垒吗？
🎮 打开Scratch在线操作

小猫跑垒 - 让角色动起来

🎯 学习目标：学会使用"当绿旗被点击"和"滑行到"积木，让角色按照路线移动。

📖 故事背景：棒球比赛开始了！小猫要从本垒出发，依次跑过一垒、二垒、三垒，最后回到本垒得分！

📝 详细操作步骤

第1步：打开编辑器并添加背景

📌 操作方法：

  1. 打开 scratch.mit.edu
  2. 点击"创建"进入编辑器
  3. 点击右下角"选择一个背景"
  4. 搜索 baseball，点击添加棒球背景

第2步：找到"当绿旗被点击"积木

📌 操作方法：

  1. 看屏幕左边，找到"事件"分类（黄色积木，图标是一个灯泡）
  2. 点击"事件"，你会看到很多黄色的积木
  3. 找到第一个积木"当 🚩 被点击"（上面有个绿旗图标）

  1. 点击左边的"运动"分类（蓝色积木）
  2. 找到"移到 x: ( ) y: ( )"积木

指南针 - 学习面向方向

🎯 学习目标：理解Scratch中的方向概念，学会使用"面向"积木。

📖 故事背景：探险家小猫在森林里迷路了，它需要用指南针找到正确的方向！

📝 详细操作步骤

第1步：认识Scratch中的方向

📌 知识点：

  • 0° = 正上方（向上）
  • 90° = 正右方（向右）➡️
  • 180° = 正下方（向下）⬇️
  • -90° 或 270° = 正左方（向左）⬅️
📝 记住：就像时钟一样！
想象你站在舞台中间，面向右边是90度，面向上面是0度！

第2步：打开Scratch创建新项目

  1. 打开 scratch.mit.edu，点击"创建"
  2. 点击右下角"选择一个背景"
  3. 搜索 forest（森林），添加森林背景

第3步：让小猫面向不同方向

📌 操作方法：

  1. 点击左边"事件"分类，拖出"当绿旗被点击"
  2. 点击左边"运动"分类
  3. 找到"面向 ( ) 度"积木
  4. 拖动拼在"当绿旗被点击"下面
  5. 在数字框输入 90
  6. 点击绿旗，看小猫是不是面向右边了？
当 🚩 被点击
面向 (90) 度

第4步：尝试不同方向

📌 试一试：把角度改成不同的数字，看看小猫面向哪里？

  • 改成 0，小猫面向上方 ⬆️
  • 改成 180，小猫面向下方 ⬇️
  • 改成 -90，小猫面向左方 ⬅️

💡 小贴士：你可以输入任何角度，比如45度就是面向右上方！

第5步：添加移动让小猫走起来

📌 操作方法：

  1. 在"运动"分类里找到"移动 ( ) 步"积木
  2. 拖动拼在"面向"积木下面
  3. 输入步数 100
  4. 点击绿旗，小猫会面向右边走100步！
当 🚩 被点击
面向 (90) 度
移动 (100) 步

🤔 课后思考题

  1. 如果要小猫面向左上角，应该填多少度？（提示：在0和-90之间）
  2. "移动100步"和"滑行到某个位置"有什么不同？
  3. 能想办法让小猫面向鼠标指针吗？

💡 进阶挑战

让小猫面向鼠标指针：

  1. 在"运动"分类里找到"面向 鼠标指针"积木
  2. 这个积木会让小猫永远面向鼠标指针的方向！
面向 (鼠标指针)

旋转指南针 - 学习旋转

🎯 学习目标：学会使用"右转"和"左转"积木，让角色旋转起来。

📖 故事背景：指南针的指针一直在不停地转动，让我们用Scratch做一个旋转的指南针吧！

📝 详细操作步骤

第1步：创建新项目

  1. 打开 scratch.mit.edu，点击"创建"
  2. 删除小猫（右键点击小猫角色，选择"删除"）
  3. 我们要画一个指针形状的角色

第2步：绘制指针角色

📌 操作方法：

  1. 点击左下角"选择一个角色"旁边的"绘制"按钮（画笔图标）
  2. 在右侧绘画区域，用线条工具画一个箭头
  3. 箭头要指向上方（这样0度就是指向上方）
  4. 点击右上角完成绘画

💡 小贴士：也可以直接用小猫角色来学习旋转，效果一样！

第3步：让指针旋转

📌 操作方法：

  1. 拖出"当绿旗被点击"积木（事件分类，黄色）
  2. 在"控制"分类（橙色）找到"重复执行"积木
  3. 拖动拼在"当绿旗被点击"下面
  4. 在"运动"分类找到"右转 ( ) 度"积木
  5. 拖动放进"重复执行"积木的嘴巴里面
  6. 在数字框输入 15
当 🚩 被点击
重复执行
右转 (15) 度

第4步：运行看效果

  1. 点击绿旗
  2. 观察指针是不是在不停地顺时针旋转？

💡 小贴士：把15改成30，转得会更快！改成5，转得更慢！

第5步：尝试逆时针旋转

📌 操作方法：

  1. 把"右转"积木换成"左转"积木
  2. 点击绿旗，观察指针是逆时针旋转了！

🤔 课后思考题

  1. 为什么指针会一直转个不停？
  2. 如果要让它转得更快，应该改哪个数字？
  3. 能做一个旋转速度时快时慢的指南针吗？
🎮 打开Scratch在线操作
