认识Scratch界面，了解基本操作方法

🐱

什么是Scratch？

Scratch是由美国麻省理工学院(MIT)媒体实验室开发的一款图形化编程工具。它采用积木块拼图的方式，让编程变得像搭积木一样简单有趣。通过Scratch，你可以创建动画、游戏、故事和互动艺术作品。

✨ Scratch的特点

🎯 图形化编程 - 无需输入代码，拖拽积木即可

🎮 丰富的素材库 - 内置大量角色、背景和音效

🌐 在线社区 - 分享作品，学习他人创意

📱 跨平台 - 支持网页版和离线版

🔗 扩展功能 - 支持micro:bit、AI、翻译等扩展

🖥️

界面介绍

📝 主要区域说明

1. 舞台区（左上角）

展示你的作品效果的地方。可以全屏观看，也可以调整舞台大小。绿旗和停止按钮控制程序的运行。

• 舞台大小：480×360像素

• 坐标系：中心(0,0)，左上(-240,180)，右下(240,-180)

• 绿旗：启动程序 | 停止：结束程序

2. 角色区（左下角）

管理项目中的所有角色和背景。可以添加、删除、复制角色，调整角色属性。

• 添加角色：从库中选择、绘制、上传、随机

• 角色属性：名称、位置、大小、方向、显示/隐藏

• 背景：每个舞台可以有多个背景

3. 积木区（中间）

存放各种编程积木的地方。按类别分组，可以搜索需要的积木。

运动 - 移动和旋转 外观 - 造型和特效 声音 - 播放音效 事件 - 触发程序 控制 - 流程控制 侦测 - 检测状态 运算 - 数学计算 变量 - 存储数据

4. 脚本区（右边）

编写程序的地方。将积木拖到这里拼接成程序脚本。

• 拖拽积木：从积木区拖到脚本区

• 拼接积木：积木会自动吸附连接

• 删除积木：拖回积木区或右键删除

• 多脚本：同一角色可以有多个独立脚本

⚙️

基本操作

📝 常用操作步骤

添加角色

1. 点击角色区右下角的"选择一个角色"按钮

2. 选择添加方式：上传、选择、绘制、随机

3. 新角色会出现在舞台和角色列表中

编写脚本

1. 点击要编程的角色

2. 从积木区拖出需要的积木

3. 将积木拼接在一起

4. 点击绿旗测试效果

添加音效

1. 点击"声音"标签

2. 选择"选择一个声音"

3. 选择或录制音效

4. 在脚本中使用"播放声音"积木

保存和分享

1. 点击菜单"文件" → "保存到电脑"

2. 在线版可点击"分享"发布到社区

3. 可以导出为.sb3文件分享给他人

💻

如何使用Scratch

📝 两种使用方式

在线版（推荐）

访问 scratch.mit.edu，注册账号后即可使用。优点是可以在任何电脑上使用，作品自动保存，方便分享。

✅ 无需安装，打开浏览器即可使用

✅ 作品自动保存到云端

✅ 可以分享作品到社区

✅ 可以查看他人作品学习

离线版

下载Scratch Desktop（Scratch Link），无需联网即可使用。适合网络不稳定或离线环境的用户。

📥 下载地址：scratch.mit.edu/download

✅ 无需网络连接

✅ 运行更流畅稳定

⚠️ 需要手动保存文件

⚠️ 分享需要导出文件

🌐 打开在线编辑器 📥 下载离线版

常用快捷键

⌨️ 快捷键列表

Ctrl + S - 保存项目

Ctrl + Z - 撤销操作

Ctrl + Shift + Z - 重做操作

Ctrl + C - 复制积木

Ctrl + V - 粘贴积木

Delete - 删除积木

空格键 - 运行/停止程序

右键 - 显示上下文菜单
