弹球游戏 - 变量入门

🎯 学习目标：学会创建和使用变量，制作一个简单的弹球游戏。

📖 故事背景：用挡板接住弹跳的小球，看看你能得多少分！

⏱️ 预计时间：30-40分钟

📝 详细操作步骤

第1步：打开Scratch并删除小猫

  1. 双击桌面上的Scratch图标，打开Scratch软件
  2. 等待软件完全加载，你会看到一只橙色的小猫
  3. 在舞台区域（右上方的白色区域），右键点击小猫角色
  4. 在弹出的菜单中，点击"删除"
  5. 小猫就消失了，舞台变成空白

💡 小贴士：删除角色是为了让舞台更清爽，我们等会儿添加需要的角色。

第2步：绘制挡板角色

📌 操作方法：

  1. 看屏幕右下角，找到"选择一个角色"按钮（小猫头像）
  2. 把鼠标移到这个按钮上，会出现四个小图标
  3. 点击"绘制"图标（画笔形状）
  4. 右侧会出现绘画区域
  5. 点击左侧工具栏的"矩形"工具（方块形状）
  6. 选择一个喜欢的颜色（点击"填充"颜色块选择）
  7. 在画布中间，按住鼠标拖动，画一个长方形
  8. 长方形大约：宽120像素，高20像素
  9. 点击右上角的"选择"工具（箭头形状），拖动调整长方形的位置到中心
  10. 点击画布上方的"角色1"，改名为"挡板"

💡 小贴士：挡板要画得长一点，这样更容易接到球！

第3步：让挡板跟随鼠标移动

📌 操作方法：

  1. 确保挡板角色被选中（点击舞台上的挡板）
  2. 看屏幕左边，点击"事件"分类（黄色积木）
  3. 拖出"当绿旗被点击"积木到中间脚本区
  4. 点击"运动"分类（蓝色积木）
  5. 找到"移到 x: ( ) y: ( )"积木，拖到"当绿旗被点击"下面
  6. 点击"控制"分类（橙色积木）
  7. 找到"重复执行"积木，拖到最下面，拼在一起
  8. 回到"运动"分类
  9. 找到"移到 x: ( ) y: ( )"积木，拖进"重复执行"的嘴巴里面
  10. 在"运动"分类最下面找到"鼠标的 x 坐标"（椭圆形）
  11. 把这个椭圆形的积木拖到 x: 后面的白色框里
  12. 在 y: 后面点击白框，输入数字 -130（挡板在舞台底部）
当 🚩 被点击
移到 x: (鼠标的 x 坐标) y: (-130)
重复执行
移到 x: (鼠标的 x 坐标) y: (-130)

✅ 测试一下：点击绿旗，移动鼠标，挡板是不是跟着左右移动了？

第4步：添加小球角色

📌 操作方法：

  1. 点击右下角"选择一个角色"
  2. 点击"选择一个角色"（搜索图标，放大镜形状）
  3. 在搜索框输入 ball
  4. 找到喜欢的球，点击添加
  5. 用鼠标拖动小球，把它移到舞台中间偏上的位置
  6. 点击小球角色，在上方名称处改名为"小球"

第5步：创建分数变量

📌 什么是变量？

变量就像一个"存东西的盒子"，可以存放数字或文字。我们需要一个"盒子"来存放分数。

📌 操作方法：

  1. 点击屏幕左边"变量"分类（深橙色积木）
  2. 点击"建立一个变量"按钮
  3. 在弹出的窗口中，输入变量名：分数
  4. 选择"适用于所有角色"（让所有角色都能看到这个变量）
  5. 点击"确定"
  6. 你会看到舞台左上角出现了"分数"显示框

💡 小贴士：现在我们有了一个叫"分数"的变量，可以随时改变里面的数字！

第6步：给小球添加起始代码

📌 操作方法：

  1. 点击小球角色（确保在编辑小球的代码）
  2. 拖出"当绿旗被点击"积木
  3. 在"变量"分类里找到"将 [分数] 设为 (0)"积木
  4. 拖到"当绿旗被点击"下面（这样每次开始游戏分数都是0）
  5. 在"运动"分类里找到"移到 x: (0) y: (0)"积木
  6. 拖到下面，设置小球的起始位置在舞台中央

📌 操作方法：

  2. 拖到脚本区，拼在"移到"积木下面

第9步：检测小球碰到挡板

📌 操作方法：

  1. 在"控制"分类里找到"如果...那么"积木（带菱形框的）
  2. 拖进"重复执行"里面，放在"碰到边缘就反弹"下面
  3. 在"侦测"分类（浅蓝色积木）里找到"碰到 [鼠标指针] ?"积木
  4. 拖到"如果"后面的菱形框里
  5. 点击"鼠标指针"旁边的小箭头，选择挡板

第10步：碰到挡板得分并反弹

📌 操作方法：

  1. 在"变量"分类里找到"将 [分数] 增加 (1)"积木
  2. 拖进"如果...那么"的嘴巴里面
  3. 在"运动"分类找到"面向 ( ) 度"积木
  4. 拖进"如果...那么"里面
  5. 在"运算"分类找到"( ) - ( )"积木
  6. 拖到"面向"的数字框里
  7. 在"运动"分类最下面找到"方向"（椭圆形）
  8. 拖到减号的第一个框里
  9. 在第二个框输入180

📌 操作方法：当小球掉到底部（Y坐标小于-140），游戏结束。

  9. 输入"游戏结束！"
  10. 在"控制"分类找到"停止 [全部脚本]"积木

  3. 能添加音效吗？在碰到挡板时发出声音？

💡 进阶挑战

打地鼠 - 随机位置与计时

🎯 学习目标：学会使用随机位置、计时器和广播消息。

📖 故事背景：调皮的地鼠从洞里冒出来，快用锤子敲它！看看60秒内你能打中多少只！

⏱️ 预计时间：40-50分钟

📝 详细操作步骤

第1步：添加背景

  1. 打开Scratch软件
  2. 删除小猫角色
  3. 点击右下角"选择一个背景"
  4. 搜索 garden 或 grass，添加一个草地背景
  5. 或者点击"绘制"，用绿色画笔画一个草地

第2步：绘制地鼠角色

  1. 点击右下角"绘制"创建新角色
  2. 用椭圆工具画一个棕色的圆形（地鼠的头，大约40x40像素）
  3. 用椭圆工具添加两个小黑色圆形当眼睛
  4. 用椭圆工具画一个粉色的鼻子
  5. 点击角色名称，改名为"地鼠"

第3步：添加地鼠被敲到的造型

  1. 点击"造型"标签（在代码标签旁边）
  2. 右键点击左边的"造型1"，选择"复制"
  3. 在第二个造型里，用画笔工具把眼睛改成X形状
  4. 或者画两道斜线在眼睛上
  5. 这个造型叫做"造型2"

💡 小贴士：第一个造型是地鼠正常的样子，第二个是地鼠被敲晕的样子！

第4步：创建变量

  1. 点击"变量"分类
  2. 点击"建立一个变量"
  3. 输入变量名：分数，点击确定
  4. 再点击"建立一个变量"
  5. 输入变量名：时间，点击确定

💡 小贴士："分数"用来记录打中地鼠的次数，"时间"用来倒计时60秒！

第5步：初始化游戏

  1. 点击地鼠角色
  2. 点击"代码"标签回到积木区
  3. 拖出"当绿旗被点击"积木
  4. 在"变量"分类找到"将 [分数] 设为 (0)"
  5. 拖到"当绿旗被点击"下面
  6. 再拖一个"将 [时间] 设为 (60)"
  7. 在"外观"分类找到"隐藏"积木

贪吃蛇 - 键盘控制游戏

🎯 学习目标：学会使用键盘控制角色移动，制作经典贪吃蛇游戏。

📖 故事背景：控制小蛇吃食物，每吃一个食物身体就会变长，不能碰到墙壁哦！

⏱️ 预计时间：50-60分钟

📝 详细操作步骤

第1步：绘制蛇头角色

  1. 打开Scratch，删除小猫
  2. 点击"绘制"创建新角色
  3. 用椭圆工具画一个绿色圆形（直径约20像素）
  4. 用画笔工具画两个小黑点当眼睛
  5. 把角色改名为"蛇头"

第2步：绘制食物角色

  1. 点击"绘制"再创建一个角色
  2. 用椭圆工具画一个红色小圆形（直径约15像素）
  3. 把角色改名为"食物"

第3步：创建变量

  1. 点击"变量"分类
  2. 创建变量：分数
  3. 创建变量：方向（用来记录蛇头朝向）

第4步：编写蛇头初始代码

  1. 点击蛇头角色
  2. 拖出"当绿旗被点击"积木
  3. 添加"将 [分数] 设为 (0)"
  4. 添加"将 [方向] 设为 (90)"（初始向右）
  5. 添加"移到 x: (0) y: (0)"（从中间开始）

画板工具 - 画笔扩展

🎯 学习目标：学会使用画笔扩展，制作绘图工具。

⏱️ 预计时间：40-50分钟

📝 详细操作步骤

第1步：添加画笔扩展

  1. 打开Scratch
  2. 点击左下角"添加扩展"（拼图形状）
  3. 点击"画笔"（Pen）图标
  4. 左边出现蓝色的"画笔"分类

第2步：创建画笔角色

  1. 删除小猫
  2. 绘制一个小圆形角色（直径5像素）
  3. 改名为"画笔"

第3步：跟随鼠标并绘制

  1. 拖出"当绿旗被点击"
  2. 添加"全部擦除"（画笔分类）
  3. 添加"重复执行"
  4. 添加"移到 x: (鼠标的 x 坐标) y: (鼠标的 y 坐标)"
  5. 添加"如果 <按下鼠标?> 那么"
  6. 里面添加"落笔"（画笔分类）
  7. 添加"否则"
  8. 里面添加"抬笔"

第4步：添加颜色选择

  1. 创建变量画笔颜色
  2. 添加多个角色作为颜色按钮
  3. 点击不同颜色按钮，改变画笔颜色
  4. 使用"将画笔颜色设为"积木

第5步：添加清除功能

  1. 添加"当按下 [空格] 键"
  2. 添加"全部擦除"

✅ 测试：点击绿旗，按住鼠标绘制，按空格清除！
